### Висновок «як зроблено кола»
- Три диски — це **три еліпси Ø25 з масштабом 0 → ~95×**, що розростаються від центру до повного покриття вʼюпорта; колір чергується чорний → білий → чорний; кожен наступний стартує, коли попередній ще росте (перекриття). Ease — «разгін» `(.65,0,.833,.833)`.

## Питання до користувача
Немає блокуючих. Рішення агента (карт-бланш):
1. Час прелоадера залишаємо фіксованим як на лайві (5.0 + 3.23 + 1.7 = 9.93 с) або скорочуємо — це дизайн-рішення на фініш; за замовчуванням 1:1.
2. Скрол під час прелоадера блокуємо (Lenis stop/`overflow:hidden`) до зникнення, потім `scrollTo(0,0)` і `lenis.start()` (на лайві такого немає — виправлення, не зміна дизайну).
3. Одна розмітка замість 3 Lottie: слова текстом, розмір слів — за cover-формулою вʼюпорта (≈ токен `display-xl` на макетних вʼюпортах 1440×750 / 768×1024 / 375×667), щоб збігатися з лайвом на інших пропорціях; якщо дизайнер хоче зафіксувати 215/120/56 — окреме рішення.
4. Лінія-фінал: opacity .8 → 1.0 (як Hero) для безшовного стику; різниця непомітна.

### Гейт і стартові стани (`src/preloader.css` + inline-скрипт у head)

Page-level custom code у Designer не виконується, тож у Designer секція — звичайний блок 100vh зверху сторінки, повністю видимий і редагований. На сайті:

```html
<style>
  .section-preloader { display: none; }
  html.is-preloading { overflow: hidden; }
  html.is-preloading .section-preloader { display: block; position: fixed; inset: 0; height: 100%; z-index: 1000; }

  html.is-preloading [data-motion="preloader-word"] { transform: translateY(100vh); }

```

- Без JS прелоадера немає взагалі (сайт не застрягає на кремовому екрані).
- Стартові стани фази 2 живуть у гейті, а не в класах. Це відступ від правила «стартовий стан у класі» (CONVENTIONS), бо інакше в Designer слова й диски не видно й не відредагувати. Ризику блимання немає: поки JS не стартував, фазу 2 закриває непрозорий `preloader-loader`.
- Hero під прелоадером отримує свої стартові стани через `gsap.set` у `initPreloader()`. Поки прелоадер закриває екран, цього не видно.

### Таймлайн

`initPreloader()` повертає Promise, який резолвиться після фази 3. Решта модулів (ScrollTrigger-секції) ініціалізуються після нього, далі `ScrollTrigger.refresh()`.

0. **Підготовка.** `window.__motionPreloader = true`; `history.scrollRestoration = 'manual'`; `scrollTo(0, 0)`; `lenis.stop()`. Брейкпоінт фіксується на старті через `gsap.matchMedia()` (≥992 / 480–991 / ≤479). Ресайз під час 10 с прелоадера не перебудовує таймлайн. Весь код — у `try/finally`, `finally` знімає `is-preloading`.
1. **Фаза 1, 0 → 5.0 с** (`preloader-loader`):
   - Відскок — `gsap.timeline({ repeat: -1 })` на 13 кадрів @24 = 0.542 с. `preloader-bounce-ball` по y: 0 → 0.355rem (f0→f4, 0.167 с, `cubic-bezier(.641,0,.702,.74)`) → 0.384rem (f4→f5, `(.271,.715,.592,1)`) → тримає (f5→f6) → 0 (f6→f13, 0.29 с, `(.167,.021,.833,1)`). Squash/stretch, transform-origin центр, лінійно: f2 1/1 → f3 .9/1.105 → f4 .825/1.075 → f5 1.2/.8 → f6 1.25/.75 → f7 .825/1.075 → f8 .91/1.075 → f10 1/1 (scaleX/scaleY = Lottie % / 200). `preloader-bounce-shadow`: scaleX 1 → .5 (f5–f7) → 1, `(.63,0,.37,1)`. rem переводимо в px через `getComputedStyle(html).fontSize`.
   - Лічильник `preloader-counter`: tween `{v: 0→100}`, 4.0 с, `ease: none`, `onUpdate` → `textContent = Math.round(v)`. На лайві `setInterval` 50 мс із тим самим темпом. Далі тримає «100».
   - Кінець фази: `max(5.0 с, document.fonts.ready)`. Слова не підуть фолбек-шрифтом. На лайві час фіксований, а шрифти маленькі, тож різниці не видно.
   - На 5.0: `preloader-loader` → `display: none` миттєво (як на лайві, без fade), відскок `kill()`.
2. **Фаза 2, 5.0 → 8.23 с** (`preloader-scene`, вкладений таймлайн рівно 3.23 с):
   - R = `Math.hypot(innerWidth, innerHeight) / 2 × 1.01`.
   - Диски `preloader-disc[i]`: `clip-path` `circle(0px at 50% 50%)` → `circle(Rpx at 50% 50%)`, ease `CustomEase "discGrow"` = `cubic-bezier(.65,0,.833,.833)`.
   - Слова `preloader-step[i] [data-motion=preloader-word]` (основа + дубль одним tween): y `+k·vh` → `−k·vh`, k = .604/.613 desktop, .545 tablet, .535 mobile. Ease слова 1 — `(.309,0,.833,.833)`, слів 2–3 — `(.35,0,.833,.833)`.
   - Позиції й тривалості в таймлайні фази, с:

     | | Диск 1 | Слово 1 | Диск 2 | Слово 2 | Диск 3 | Слово 3 |
     |---|---|---|---|---|---|---|
     | desktop ≥992 | 0 / 1.35 | 0.17 / 1.24 | 0.94 / 1.37 | 1.28 / 1.06 | 1.82 / 1.36 | 2.09 / 1.11 |
     | tablet 480–991 | 0 / 1.46 | 0.15 / 1.37 | 0.82 / 1.48 | 1.11 / 1.21 | 1.58 / 1.48 | 1.81 / 1.41 |
     | mobile ≤479 | 0 / 1.54 | 0.14 / 1.45 | 0.92 / 1.56 | 1.06 / 1.30 | 1.65 / 1.55 | 1.73 / 1.49 |

   - На 3.23 екран повністю чорний (диск 3 = `neutral-1000` = фон Hero).
3. **Фаза 3, 8.23 → 9.93 с — вхід Hero (рішення агента).** На лайві тут окремий дубль Hero всередині прелоадера: кільце, кулька, лінія з opacity .8 і текст. Його знімають на 9.93 с, і є шов (лінія .8→1) і стрибок, якщо сторінку під ним проскролено. У перезбірці дубля немає. На 8.23 `section-preloader` → `display: none`, `is-preloading` знімається, і анімуються **справжні елементи Hero** (ролі з docs/script-map.md, ставляться в проході Hero):
   - `hero-ball-border` + `hero-ball`: scale 0 → 1 за 0.6 с, `(.17,.17,.2,1)`; opacity 0 → 1 за 0.1 с.
   - текст hero (роль `hero-text`, додати в script-map): y `50vh` → 0 за 1.1 с, `(.17,.17,.29,1)`.
   - `hero-divider` × 2 (`data-side`): scaleX 0 → 1 від кільця назовні за 1.5 с, delay 0.2, `(.17,.17,.01,1)`, opacity лінії 1 (як Hero).
   - навбар (`nav`, роль проходу Navigation): y −200% → 0; `sound-btn`: scale 0 → 1 — обидва 0.6 с, delay 0.2, `(.17,.17,.29,1)`.
   - кінець (9.93 с): `lenis.start()`, `ScrollTrigger.refresh()`, подія `document.dispatchEvent(new Event('motion:preloader-done'))`, resolve.
4. **`prefers-reduced-motion: reduce`:** без відскоку, слів і дисків. Лічильник одразу 100, через 0.4 с `section-preloader` fade-out 0.4 с, Hero одразу в кінцевому стані, далі як у кроці 3 (кінець).

### `data-motion` ролі прелоадера (дописати в docs/script-map.md)

`preloader`, `preloader-loader`, `preloader-bounce-ball`, `preloader-bounce-shadow`, `preloader-counter`, `preloader-scene`, `preloader-step` (×3, порядок DOM = порядок у таймлайні), `preloader-disc` (×3), `preloader-word` (×6, по 2 на крок). Фаза 3 бере ролі Hero / Navigation / Sound.

### Що звірити з записом після підключення коду

- Перекриття дисків (у кадрі видно мале біле коло всередині чорного, що ще росте) і момент, коли слово перетинає центр (диск ≈ Ø740 на 1440×750).
- Розмір слів на 1440×900 (≈258) і 375×812 (≈50).
- Безшовний перехід 8.23 (чорний → кільце росте) без кадру з видимим Hero до старту scale.
