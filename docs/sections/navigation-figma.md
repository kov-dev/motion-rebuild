- **Один компонент `Header`** (в Header-інстансах стоїть `data-name="Header"`). Інстанси розміром 1372×44, позиція (34,34) у кожному 1440×750-фреймі (поля 34 = 1440−34−34).

Решта варіантів (dark «Menu», coloured «Menu») — **кольорові перевизначення інстансів**: у dark `I788:28217;675:12367`, у coloured вкладений ще один `Header` (`I784:27394;678:12835`, `I1553:20702;678:12835`) з іншими заливками. Тому окремих ID компонент-варіантів для light/dark не знайдено через MCP (`mainComponent` не віддається get_metadata/get_design_context; потрібен `use_figma`, не робилось).
- Старий шар `Group 549` (90×44, `hidden`) у Header — прихований залишок старого лого.
- Лайв-навбар НЕ описуємо тут (розбіжності див. нижче).

## Що в Figma НЕ видно / питання

1. **Лише 3 з 10 карток** у 1440 / 3 у 375 / 5 у 768; ні назв (Fade in/out, Transformation/morph, Masking, Dimension, Parallax, Zoom, Courses & sources), ні ілюстрацій. Усе брати з лайву.
2. 768/375: Safari/iPhone chrome (`1738:23161`, `1738:23515`) — мокап, **y навбара зсунутий** (99/42 замість ~24/22): верх брати з лайву.
3. Іконка лого: у меню (Close) білі «очі» **з зірочками**, на dark-hero — **білі «очі» без зірочок**, на кольорових — чорні «очі» з зіницею. Схоже на **три різні версії лого**; на лайві перевірити, що зараз.
4. Breadcrumb `Item_scroll` у Figma — окремий шар, стоїть **x=250 y=34**, радіус 25.5, `#C8CFE8`; у лайві — окремий елемент? Не видно, як він поводиться (скрол-тригер, появи, зменшення) — у Figma лише 1 стан.
5. Hover/active станів кнопок немає (ні Menu, ні close, ні Sound, ні карток). Hover на меню-картках — лише активна (0, радіус 24, білий border) vs неактивна (radius 0, `#727272`): це, ймовірно, **стан поточної/наведеної**, радіус різний — Figma-невідповідність (радіус 24 vs 0 — можливо старий дизайн).
6. Закритий стан burger і тогл на 375/768 не намальовані; зрозуміти точно по записах.
7. Невідомо, чи кнопка `menu` без тексту на ≤479 (по 375: тільки іконка) і на 768 лишається з текстом (у 768 — `close` з текстом).
8. Нижній рядок 1440: «Site by Zajno», без соцмереж; 768/375: «Made by Zajno» + 5 іконок (з ознакою 4-ї «facebook»-обгортки, всередині linkedin). **Різні версії**.
9. Заголовок меню 1440 / Rectangle 12763 / текст «Motion design principles» — залишки старого кадру, не візуальні.
10. Кегль заголовків карток на 375 не підтверджено (текст w=144, h=18).
11. `mainComponent` id Header-символа не віддається MCP-метаданими; `1221:42413` — лише inner node варіанту Close.
