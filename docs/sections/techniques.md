## План анімації (сесія 15) — код, не IX3

**Рішення агента (карт-бланш): `initTechniques()` у `src/motion.js`**, а не IX3:
1. Секцію зсувають pin-spacer'и Intro (UI-слайдер) і Interactive, які створює наш код. Тригер Techniques має
   створюватися **після них у тому самому ScrollTrigger** і перераховуватися тим самим `refresh()` — з IX3 (окремий
   рантайм Webflow) порядок і refresh не контролюємо, а саме неузгоджені тригери дали баг стрибка скролу на мобайлі.
2. Три варіанти по смугах (старт 30 % на ≤991, −3rem на ≤767) — один `gsap.matchMedia()` замість трьох інтеракцій.
3. Значення в rem — функції від `html` font-size + `invalidateOnRefresh`; `prefers-reduced-motion` — статичний кадр 0.

Ескіз:
```js
// Techniques: scroll-scrubbed word / star / text transforms (port of IX2 e-632/633/634).
export function initTechniques() {
  const sec = document.querySelector('.section-techniques'); // trigger = section with words inside
  const [w1, w2, w3] = q('[data-motion="techniques-word"]'), [s1, s2] = q('[data-motion="techniques-star"]');
  const text = sec.querySelector('[data-motion="techniques-text"]');
  const rem = (v) => () => v * parseFloat(getComputedStyle(document.documentElement).fontSize);
  mm.add({ tablet: '(max-width: 991px)', small: '(max-width: 767px)' }, ({ conditions: c }) => {
    const tl = gsap.timeline({ defaults: { ease: 'none' }, scrollTrigger: {
      trigger: sec, start: c.tablet ? '30% bottom' : 'top bottom', end: 'bottom top', scrub: 1, invalidateOnRefresh: true } });
    tl.fromTo(w2, { y: rem(1) }, { y: rem(-2), duration: 0.5 }, 0)
      .fromTo(w3, { y: 0 }, { y: rem(c.small ? -3 : -5), duration: 0.6 }, 0)
      .fromTo(s1, { scale: 1, y: 0 }, { scale: 0.4, y: rem(-0.6), duration: 0.26 }, 0)
      .fromTo(s2, { scale: 1, y: 0 }, { scale: 0.4, y: rem(-1), duration: 0.24 }, 0)
      .fromTo(text, { scale: 1 }, { scale: 0.6, duration: 0.12 }, 0.6)
      .set({}, {}, 1); // pad timeline to progress 1
  });
}
```
- `rotate` слів лишається в класах; GSAP читає його з matrix і зберігає (`rotation` у gsap-кеші) — перевірити, що
  `y` не скидає кут (інакше задати `rotation` явно в `fromTo`).
- smoothing 90 IX2 ≈ `scrub: 1` (як у Interactive) — підібрати по запису `05-techniques` (повільний кліп).
- Стартовий стан (слово 2 на +1rem) — **ставить код**, не клас: без JS слова стоять рівно (як Intro, сесія 9).
- Перевірка: `techniques-run.mjs` за зразком `interactive-run.mjs` — transform слів/зірок/абзацу на тих самих 8 точках
  прогресу, що в `techniques-probe.mjs`, проти лайву (`--live` на staging після підключення).
- Разом із кодом: перенести `id="techniques"` на нову секцію, коли стару буде видалено (меню старого навбара).
